# ربات تلگرام یادآوری کارهای روزانه

این ربات به شما اجازه می‌دهد کارهای روزانه‌ی خود را ثبت کنید و هر روز، سر ساعت دلخواه، یادآوری خودکار آن‌ها را دریافت کنید.

## امکانات

- ثبت کار جدید (`/add`)
- مشاهده‌ی لیست کارها (`/list`)
- حذف یک کار انجام‌شده (`/done`)
- پاک کردن کل لیست (`/clear`)
- تنظیم ساعت دلخواه برای یادآوری روزانه (`/settime`)
- یادآوری خودکار هر روز، سر همان ساعت، برای هر کاربر به‌صورت جداگانه

## مراحل راه‌اندازی

### ۱. ساخت ربات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
2. دستور `/newbot` را بفرستید و مراحل را طی کنید (انتخاب نام و یوزرنیم).
3. یک **توکن** به شما داده می‌شود، شبیه به:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### ۲. نصب پیش‌نیازها

روی سیستم خودتان (یا یک سرور) دستورات زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

### ۳. وارد کردن توکن

فایل `bot.py` را باز کنید و این خط را پیدا کنید:

```python
BOT_TOKEN = "PUT_YOUR_TELEGRAM_BOT_TOKEN_HERE"
```

و توکن واقعی خودتان را جایگزین کنید:

```python
BOT_TOKEN = "123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### ۴. اجرای ربات

```bash
python3 bot.py
```

اگر پیام «ربات در حال اجراست...» را دیدید یعنی ربات فعال شده. حالا در تلگرام سراغ ربات خودتان بروید و `/start` را بفرستید.

## استفاده روزمره

| دستور | توضیح |
|---|---|
| `/start` | شروع و مشاهده‌ی راهنما |
| `/add خرید نان` | افزودن کار جدید |
| `/list` | نمایش لیست کارهای فعلی |
| `/done 2` | حذف کار شماره‌ی ۲ از لیست |
| `/clear` | پاک کردن همه‌ی کارها |
| `/settime 08:30` | تنظیم ساعت یادآوری روزانه به ۸:۳۰ صبح |
| `/mytime` | نمایش ساعت یادآوری فعلی |

پیش‌فرض یادآوری هر روز ساعت **۹:۰۰ صبح** به وقت تهران (Asia/Tehran) است؛ با `/settime` می‌توانید آن را تغییر دهید.

## نکته‌ی مهم درباره‌ی روشن ماندن ربات

این ربات باید همیشه در حال اجرا باشد تا بتواند یادآوری‌های روزانه را ارسال کند. برای این کار می‌توانید:

- آن را روی یک **سرور VPS** ارزان (مثلاً با Ubuntu) اجرا کنید و با ابزاری مثل `systemd` یا `pm2` یا `tmux`/`screen` همیشه فعال نگه دارید.
- یا از سرویس‌های میزبانی رایگان/ارزان پایتون مثل Railway، Render یا PythonAnywhere استفاده کنید.

روی سیستم شخصی (لپ‌تاپ) هم اجرا می‌شود، اما با خاموش شدن سیستم، یادآوری‌ها هم متوقف می‌شوند.

## ساختار داده

اطلاعات کارها و ساعت یادآوری هر کاربر در یک فایل دیتابیس سبک به نام `goals.db` (SQLite) در همان پوشه ذخیره می‌شود و نیازی به سرور دیتابیس جداگانه ندارد.

## توسعه‌های پیشنهادی بعدی

- افزودن دسته‌بندی برای کارها (کاری، شخصی، خرید و ...)
- یادآوری چند بار در روز
- دکمه‌های شیشه‌ای (inline keyboard) برای تیک زدن سریع‌تر کارها
- پشتیبانی از یادآوری‌های هفتگی/تک‌باره با تاریخ مشخص
