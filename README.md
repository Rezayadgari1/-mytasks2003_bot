# 🎯 MyTasks — ربات هوشمند مدیریت کارهای روزانه تلگرام

ربات تلگرامی جامع برای مدیریت اهداف، یادآوری خودکار، سیستم VIP، دعوت دوستان، تولد، هوش مصنوعی و بیشتر.

## ✨ امکانات

### هسته اصلی
- 🎯 ثبت و مدیریت اهداف روزانه با اولویت و مدت زمان
- ⏰ یادآوری خودکار روزانه برای هر کاربر به‌صورت جداگانه
- 📅 جدول هفتگی و آمار پیشرفت
- 🏆 سیستم دستاوردها (Achievements)
- ✏️ اهداف آماده در ۱۰ دسته (سلامتی، ورزش، مطالعه، ...)
- 📋 مراحل (Steps) برای هر هدف
- 💤 Snooze یادآوری (۱۰، ۳۰، ۶۰ دقیقه)

### سیستم VIP و XP
- ⭐ سیستم XP و سطح‌بندی کاربران
- 💎 اشتراک VIP با پرداخت Telegram Stars
- 🤝 سیستم دعوت دوستان با پاداش دوطرفه
- 🎁 هدایای تولد و مناسبتی

### هوش مصنوعی
- 🤖 چت با AI ( OmniRoute → OpenAI → n8n → Gemini )
- 🎙️ پشتیبانی صوتی

### مدیریت کانال
- 📢 انتشار خودکار پست‌ها در کانال
- 📊 نظرسنجی و واکنش‌ها
- 🗓️ زمان‌بندی پست‌ها

### قیمت آنلاین
- 📈 قیمت دلار، بیتکوین، اتریوم، تتر، S&P 500، طلا
- 🔔 هشدار قیمت

### سیستم مشتری و نوبت‌دهی
- 👥 مدیریت مشتریان و قرارها
- 📅 تقویم کاری و ساعات فعالیت
- 🔗 لینک رزرو آنلاین عمومی

### تولد و مناسبت‌ها
- 🎂 ثبت تولد با تقویم شمسی و میلادی
- 🎁 اهدای خودکار هدیه تولد (XP/VIP)
- 📅 مدیریت مناسبت‌ها

### امنیت و مدیریت
- 🛡 سیستم دسترسی (RBAC) با نقش‌های مدیر و مالک
- 🔒 لاگ امنیتی رویدادها
- 📊 گزارش‌های مدیریتی (کاربران، مالی، خطاها، ...)

## 🚀 راه‌اندازی

### ۱. ساخت ربات در تلگرام
1. به [@BotFather](https://t.me/BotFather) پیام بدهید
2. `/newbot` بفرستید و مراحل را طی کنید
3. توکن ربات را کپی کنید

### ۲. نصب و اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن_خود_اینجا"
python3 bot.py
```

### ۳. اجرا با Docker

```bash
docker build -t mytasks-bot .
docker run -e BOT_TOKEN="توکن_خود_اینجا" mytasks-bot
```

### ۴. متغیرهای محیطی اختیاری

| متغیر | توضیح |
|--------|-------|
| `BOT_TOKEN` | توکن ربات تلگرام (اجباری) |
| `DB_PATH` | مسیر فایل دیتابیس (پیش‌فرض: `goals.db`) |
| `ADMIN_IDS` | شناسه‌های مدیران با کاما (مثلاً `123,456`) |
| `OPENAI_API_KEY` | کلید API اوپن‌ای‌آی برای چت AI |
| `GEMINI_API_KEY` | کلید API Gemini |
| `OMNIROUTE_BASE_URL` | آدرس OmniRoute gateway |
| `REQUIRED_CHANNEL_URL` | لینک عضویت اجباری کانال |

## 📝 نکات فنی

- **دیتابیس:** SQLite با WAL mode و backup خودکار
- **مایگریشن:** فقط افزایشی (Additive) — هیچ داده‌ای حذف نمی‌شود
- **امنیت:** لاگ رویدادهای امنیتی، کنترل دسترسی سطحی، محافظت حساب مالک
- ** languages:** فارسی و انگلیسی ( bilingual UI )
- **ساعت:** Asia/Tehran (بهوقت تهران)
