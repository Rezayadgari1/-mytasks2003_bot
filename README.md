# 🤖 ربات تلگرام MyTasks — برنامه‌ریز اهداف و یادآوری روزانه

ربات فارسی/انگلیسی مدیریت اهداف روزانه با یادآوری خودکار، آمار، تقویم شمسی، سیستم XP و دستاوردها، دعوت دوستان، چت هوش مصنوعی و بخش VIP.

## امکانات

- 🎯 ثبت اهداف آماده (در ۱۰ دسته) یا نوشتن هدف دلخواه
- ⏰ یادآوری خودکار هر هدف در ساعت تعیین‌شده (به وقت تهران)
- 🔁 تکرار یادآوری با بازه زمانی مشخص + تاریخ پایان دوره
- 📅 تقویم شمسی (جلالی) برای مشاهده اهداف هر روز
- 📊 آمار، جدول هفتگی و پروفایل شخصی
- ⭐ سیستم XP و 🏆 دستاوردها
- 🤝 دعوت دوستان (`/referral`)
- 🤖 چت با AI (پشتیبانی از OmniRoute / OpenAI / Gemini / n8n)
- 💎 بخش VIP با پرداخت داخل ربات
- 📈 نمایش قیمت آنلاین (`/prices`)
- 👨‍💼 پنل مدیریت کامل (`/admin`) شامل پیام همگانی، تنظیم کانال اجباری و مدیریت قابلیت‌ها

## مراحل راه‌اندازی

### ۱. ساخت ربات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
2. دستور `/newbot` را بفرستید و مراحل را طی کنید.
3. توکن دریافتی را نگه دارید.

### ۲. نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی

توکن **داخل فایل نوشته نمی‌شود**؛ از طریق متغیر محیطی تنظیم کنید:

```bash
export BOT_TOKEN="123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

متغیرهای اختیاری:

| متغیر | توضیح |
|---|---|
| `DB_PATH` | مسیر فایل دیتابیس SQLite (پیش‌فرض: `goals.db` کنار اسکریپت). روی Railway یک مسیر روی Volume پایدار بگذارید. |
| `ADMIN_IDS` | شناسه‌های عددی تلگرام ادمین‌ها، جدا شده با کاما (مثلاً `123456789,987654321`) |
| `REQUIRED_CHANNEL_URL` | لینک عضویت کانال اجباری |
| `GEMINI_API_KEY` / `OPENAI_MODEL` / `OMNIROUTE_*` / `N8N_*` | تنظیمات اختیاری هوش مصنوعی |

### ۴. اجرای ربات

```bash
python3 bot.py
```

## استفاده

ربات منوی اصلی دکمه‌ای دارد؛ دستورهای متنی موجود:

| دستور | توضیح |
|---|---|
| `/start` | شروع و نمایش راهنما |
| `/admin` | پنل مدیریت (فقط ادمین‌ها) |
| `/prices` | قیمت آنلاین ارز/طلا |
| `/xp` | امتیاز XP شما |
| `/referral` | لینک دعوت دوستان |
| `/support` | ارتباط با پشتیبانی |
| `/myid` | نمایش شناسه عددی تلگرام شما |
| `/seclog [تعداد]` | رویدادهای امنیتی اخیر (فقط ادمین) |

سایر عملیات (افزودن هدف، یادآوری‌ها، تقویم، آمار، تنظیمات و...) از طریق دکمه‌های منوی داخل چت انجام می‌شود.

## نکته‌ی مهم درباره‌ی روشن ماندن ربات

این ربات باید همیشه در حال اجرا باشد تا یادآوری‌ها ارسال شوند:

- اجرا روی **سرور VPS** با `systemd` یا داخل `tmux`/`screen`
- یا سرویس‌هایی مثل Railway، Render یا PythonAnywhere

روی سیستم شخصی هم اجرا می‌شود، اما با خاموش شدن سیستم، یادآوری‌ها متوقف می‌شوند.

## ساختار داده

اطلاعات کاربران، اهداف، پرداخت‌ها و تنظیمات در فایل SQLite (پیش‌فرض `goals.db`) ذخیره می‌شود. نسخه اسکیما: ۲۵ — مهاجرت‌ها افزایشی هستند و داده‌های کاربران در به‌روزرسانی‌ها حفظ می‌شود. یک نسخه پشتیبان خودکار نیز کنار دیتابیس نگه داشته می‌شود.

## امنیت

- تمام کوئری‌ها پارامتری هستند و داده هر کاربر با `user_id` کاملاً جدا نگه‌داری می‌شود.
- هر تلاش برای دسترسی به هدف کاربر دیگر، و هر تلاش ناموفق برای ورود به پنل مدیریت، در جدول `security_events` ثبت می‌شود.
- ادمین‌ها می‌توانند با `/seclog` آخرین رویدادهای امنیتی را ببینند.

## توسعه‌های پیشنهادی بعدی

- دسته‌بندی سفارشی برای کاربران
- یادآوری چند بار در روز برای یک هدف
- خروجی CSV از تاریخچه
- پشتیبانی از یادآوری‌های هفتگی/تک‌باره با تاریخ مشخص
