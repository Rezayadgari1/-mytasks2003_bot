Mosaicybot - تشخیص آهنگ از لینک ویدیو

این نسخه:
- لینک ویدیو را از سایت‌های پشتیبانی‌شده توسط yt-dlp می‌گیرد.
- صدای ویدیو را جدا می‌کند.
- آهنگ را با AudD تشخیص می‌دهد.
- نام آهنگ، خواننده، آلبوم و لینک Spotify یا Apple Music را می‌فرستد.
- فایل ویدیو یا صوتی ارسالی در تلگرام را نیز بررسی می‌کند.

نیازها:
1. یک توکن جدید از BotFather
2. یک API Token از AudD
3. اجرای برنامه روی سرور یا سرویس ابری
4. ffmpeg

تنظیم:
BOT_TOKEN و AUDD_TOKEN را در Environment Variables قرار بده.

اجرای محلی:
pip install -r requirements.txt
python bot.py

نکته:
توکن قدیمی ربات که قبلا در چت فرستاده شد، استفاده نشود. در BotFather آن را با /revoke باطل کن و توکن جدید بگیر.
